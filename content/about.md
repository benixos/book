# About this book

A description of BenixOS, the distributed operating system built from Kits over the Hearth protocol: its design, and what exists today.

It is not a specification. The node contract and the Hearth spec are the normative documents.

## State boxes

Each chapter opens with a **State** box. **Built** means code exists and is tested. **Partial** means something real exists but a stated part does not. **Draft** means a written design with no code. **Planned** means named in a plan, with no design and no code.

Kit statuses use the registry's words: design, scaffold, alpha, pre-release, stable. **No Kit is `stable`.**

## Status

Written in November 2026. Most of the code described is unpublished, and parts of it change often. Where a page and a repository disagree, the repository is right.
